# Job Search Head Hanter

Получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно работать с ней:
добавлять, фильтровать, удалять.
## Возможности

1. ### Подключение к API и получение вакансий
    #### 1.1 Класс для работы с API

- Работа с платформой hh.ru. Класс умеет подключаться к API и получать вакансии.

2. ### Работа с вакансиями
    #### 2.1  Класс для работы с вакансиями
- Определены отрибуты класса. Класс поддерживает методы сравнения вакансий между собой по зарплате и валидирует данные,
которыми инициализируются его атрибуты.

3. ### Работа с JSON файлом
    #### Класс для работа с JSON файлом
- Определен абстрактный класс, который обязывает реализовать методы для добавления вакансий в файл,
получение данных из файла по указанным критериям и удаления информации о вакансиях.
Создан класс для сохранения информации о вакансиях в JSON-файл.

4. ### Взаимодействие с пользователем
    #### Класс для взаимодействие с пользователем
- Функция взаимодействует с пользователем через консоль. Возможности этой функции следующие:
1. Ввести поисковый запрос для запроса вакансий из hh.ru;
2. Получить топ N вакансий по зарплате (N запрашивать у пользователя);
3. Получить вакансии с ключевым словом в описании.

- Покрытие тестами (100%)
- Гибкая структура проекта с использованием `Poetry`, `pytest`,`requires-python`

---

## Быстрый старт

1. **Запустите приложение:**

```bash
poetry run python main.py
```

2. **Запустите тесты:**

```bash
poetry run pytest --cov=tests
```
